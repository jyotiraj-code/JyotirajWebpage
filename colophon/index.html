ARCHITECTURAL DESIGN MANIFESTO [ZERO TRACKING]

The modern web is congested with bloated client-side bundles, parasitic user telemetry, cookie consent banners, and floaty consumer animations that treat readers as algorithmic consumers rather than intellectual peers.

This digital ledger rejects those conventions. It is constructed upon five deliberate principles:

  1. Tactile Analog Materiality: The layout evokes mid-century academic journals, lab notebooks, and mechanical typewriter consoles. Borders are strictly 1px; margins are calibrated to ledger grid dimensions.
  2. Intellectual Density: Content is presented with unapologetic rigor. Mathematical equations, Slurm scripts, and Julia kernels are rendered with full precision via KaTeX.
  3. Zero Telemetry: No analytics trackers, no Google Tag Manager, no Facebook pixels, no fingerprinting scripts. Your visit leaves no surveillance exhaust.
  4. Static First Performance: Every page is static HTML/CSS/JS. Assets load instantly from edge caches with minimal CPU overhead.
  5. Print Fidelity: Pressing Cmd + P activates a dedicated physical laboratory print stylesheet, transforming the screen into a ready-to-sign archival ledger sheet.
